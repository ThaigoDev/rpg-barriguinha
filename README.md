# A Lenda dos Seis

Soulslike 2D em pixel art, jogado direto no navegador. Dark Souls com humor brasileiro, estrelando os seis amigos de Neversk.

## Como jogar

Abra o `index.html` no navegador. Não precisa instalar nada.

| Tecla | Ação |
|---|---|
| A / D ou ← / → | Mover |
| W / ↑ / Espaço | Pular (↓ + pular desce da plataforma) |
| Shift | Rolar |
| J | Ataque leve |
| K | Ataque forte |
| L | Especial do personagem |
| Q | Café (cura) |
| E | Interagir (fogueira, NPC, mensagens) |
| Esc | Pausa |

No celular aparecem botões na tela.

## Capítulo 1: Vila dos Esquecidos

- Fogueiras para descansar e subir de nível (Vida, Vigor, Força)
- Inimigos: Morto-vivo, Cavaleiro Oco e o Caramelo Amaldiçoado
- Chefe: O Guardião Sem Rosto (duas fases)
- Ao morrer, as almas ficam no chão e podem ser recuperadas
- Progresso salvo no navegador, separado por personagem

## Tecnologia

HTML5 Canvas e JavaScript puro, num único arquivo e sem dependências.
